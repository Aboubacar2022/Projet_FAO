# Réalisez une étude de santé publique avec Python

## 📌 Contexte du projet

Ce projet s’inscrit dans le cadre d’une étude de santé publique réalisée pour la **FAO (Food and Agriculture Organization)**, un organisme de l’ONU dont la mission est de lutter contre la faim dans le monde.

L’objectif est d’analyser des données alimentaires mondiales afin d’évaluer la situation de la sous-nutrition et la capacité alimentaire globale à nourrir la population.

---

## 🎯 Objectifs du projet

- Analyser la situation de la **sous-nutrition dans le monde**
- Estimer la **proportion de personnes sous-alimentées en 2017**
- Calculer le **nombre théorique de personnes pouvant être nourries**
- Comparer les capacités alimentaires **totales** et **végétales**
- Étudier la **disponibilité intérieure alimentaire**
- Répondre aux besoins métiers formulés par différents interlocuteurs (Marc, Julien, Mélanie)

---

## 🗂️ Données utilisées

Les données proviennent de plusieurs fichiers FAO et couvrent notamment :

- 🌍 Population mondiale
- 🍞 Disponibilité alimentaire
- 🥗 Aide alimentaire
- ⚠️ Sous-nutrition

Chaque jeu de données fait l’objet d’une phase de **découverte, nettoyage et analyse exploratoire**.

---

## 🛠️ Technologies et librairies

Le projet a été réalisé avec **Python** dans un notebook Jupyter, en utilisant principalement :

- `pandas` – manipulation et analyse de données
- `numpy` – calculs numériques
- `matplotlib` / `seaborn` – visualisation de données
- `jupyter notebook` – environnement de travail

---

## 📊 Analyses réalisées

- Analyse exploratoire des jeux de données
- Calcul des indicateurs clés de sous-nutrition
- Estimation du potentiel alimentaire mondial
- Comparaison entre ressources alimentaires animales et végétales
- Mise en relation des données populationnelles et alimentaires
