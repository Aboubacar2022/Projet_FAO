# 📊 Projet – Réalisez une étude de santé publique

## 📌 Contexte
Ce projet est réalisé dans le cadre de la formation **Data Analyst – OpenClassrooms**.  
L’objectif est d’utiliser **Python** et **Jupyter Notebook** pour analyser un jeu de données, produire des visualisations pertinentes et répondre à une problématique métier.

## 🎯 Objectifs pédagogiques
- Nettoyer et préparer un jeu de données
- Réaliser une analyse exploratoire
- Produire des visualisations claires et interprétables
- Utiliser les bibliothèques Python adaptées à l’analyse de données
- Présenter des conclusions basées sur les résultats obtenus

## 🛠️ Technologies et outils
- **Python 3**
- **Jupyter Notebook**
- Bibliothèques utilisées :
  - pandas
  - numpy
  - matplotlib
  - seaborn

## Identification de besoins
Les Informations demandées sont les données sur l'année 2017

- la proportion de personnes en état de sous-nutrition
- le nombre théorique de personnes qui pourraient être nourries avec la disponibilité alimentaire mondiale et des produits végétaux
- Utilisation de la disponibilité extérieure
- Proportion des pays où les personnes sous-alimentées est plus forte en 2017

  
### Nous avons 4 fichiers de données

- Un fichier Disponibilité alimentaire qui contient 17 variables
- Un fichier population avec 3 variables
- Un fichier Aide Alimentaire avec 4 variables
- Un fichier sous-nitrution avec 3 variables
